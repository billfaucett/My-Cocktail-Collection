Fix: menu export showed every menu's drinks

MenuItemListView.swift · 5 lines changed · not yet committed

What was wrong

  • The Save To Files button gave the export every menu item from every menu, so one menu's text file included drinks from all your menus.
  • Number of Cocktails counted every menu item in the app, not just the ones in this menu.
  • The Save button only appeared once a menu had two or more drinks (count > 1).

Why each line changed

  • Filter moved up: myMenuItems is now created before the count, so the count can use it.
  • Count: it now counts only this menu's drinks.
  • Button visibility: Save To Files now appears as soon as a menu has at least one drink.
  • Export call: it now passes only this menu's drinks.
  • Function signature: filtering produces a plain array ([MenuItem]), so exportNotes now takes one. Nothing inside the function had to change.

How to test

  1. Create two menus and add different drinks to each.
  2. Open one menu and check that the count matches its drinks.
  3. Tap Save To Files, then open Files › On My iPhone › My Cocktail Collection › Menus. The file should list only that menu's drinks.
  4. Make a menu with one drink and check that the Save button appears.
